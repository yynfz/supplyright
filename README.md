# SupplyRight

**Turning Supply Commitments into Enforceable Digital Rights** — testnet prototype (Ethereum Sepolia).

> Work in progress. Smart contracts and the Foundry test suite are in `contracts/`.
> The web application, deployment guide and demo script are being added.

```bash
cd contracts
forge test
```

All monetary values are fictional testnet values denominated in **mETH** (MockETH, an ERC-20 test token with no value).
